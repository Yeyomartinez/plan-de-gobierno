# Plan de Gobierno: Raíces Comunes 2028 – 2031

Recorrido interactivo por el programa de gobierno **Raíces Comunes** para La Ceja del Tambo y La Unión (Antioquia): territorio, diagnóstico, árboles de problemas y soluciones, 20 programas bandera y metas a 2031.

Proyecto académico, Planeación del Desarrollo (Geomática, X semestre).

La página es un único archivo (`index.html`) sin dependencias locales.
